'''beta.diep.io''' is a test server for [[diep.io]]. It introduces a few new tanks and mechanics.

After being delayed for years, it finally has been added to diep.io a while before Halloween, this version replaces the original diep.io.

== General Differences ==

=== Modes ===

* The minigames have a shorter rotation time than in the main game most of the time (time depend on what the developer set it to).

=== Tanks ===

* There are new tanks that aren't available in the main game, which might eventually be added. As of the time of this edit, there is no new tank being planned as they were all added to the main game.
* Some tanks would have different stats from their main game counterparts as a result of balance testing. 
* Players can suggest their ideas on balancing with the developer, and they might be implemented for testing.

=== Miscellaneous ===

* Most of the time, Sandbox Cheats would be enabled in all lobbies, allowing convenient in testing. 

* Rarely, Dev Cheats would be enabled in a lobby, and it contains not only the basic Sandbox cheats, but also extra cheats such as:
** '''Dev: Super Saiyan Mode''': Gives the player 160 skill points and sets the skill point cap to 20.
** '''Dev: See Whole Map''': Will increase FoV to the point the entire map is visible and sets the camera to the center.
** '''Max Level''': Now can set the player all the way to level 200.

=== [[Dual-Barrel Shot|Dual Barrel Shot]] ===
The Dual Barrel Shot is a tier 4 tank that upgrades from the Shotgun at level 45. The Dual Barrel Shot features a mechanic where the left mouse button fires the left [[Cannons|barrel]] (cannon) and the right mouse button fires the right barrel. Each barrel fires 12 bullets.

=== [[Pellet Shot]] ===
The pellet shot is a tier 4 tank that upgrades from the Shotgun at level 45. The Pellet shot features a circular tank body as a base with a small modified version of the [[Battleship]]'s spawners along with a similarly sized inverted version on one end. The Pellet Shot fires 30 small bullets at the same time.

=== [[Protector (tank)|Protector]] ===
The Protector looks like an [[Overseer]] but with 3 small but very spammy [[Cannons|barrels]]. The barrels are extremely similar to the Gunner Dominator's. Its spawners spawn uncontrollable swarm drones, slightly larger than normal swarm drones, which orbit the player unlike normal swarm drones, and last longer than normal swarm drones. It can have up to 20 uncontrollable swarm drones if there are 0 points on reload.

=== Spectator ===
This looks exactly like the Spike but invisible. It only has 1 skill: Movement Speed. It has 1 health and 0 body damage.
== Hexagon ==
A new [[Polygons|polygon]] is added - [[Hexagon]]. It gives 1500 XP, and has 1500 HP. It takes 1715 hits from a Basic Tank with no points on Bullet Penetration or Bullet Damage to kill it. 

It has 16 Body Damage. 

Before September 19, 2025, it was [[Square]] sized, took 3 hits from a Basic Tank with no points on Bullet Penetration or Bullet Damage to kill it, and it had 10 HP, 8.4 Body Damage, and gave 25 XP. It was later buffed to 800 HP, 800 XP and 16 Body Damage. It would be buffed again. 
== Trivia ==

* Before September 23, 2025, on tablet, the joystick settings and class tree button will appear, but the joysticks will not load, and the upgrades and skill points will not be the mobile version.
* Not all regions are available. Sometimes Atlanta or an unknown is the only one. Sometime up to 3 are available
* Shotgun is the only Tier 3 Tank without any achievement associated with it.
* The player can see all [[achievements]], with earned ones in color, by moving their mouse to the right side of the screen.
* The Arena Closers could instantly wake up and start killing players immediately.
* Domination used to have different amounts of teams.
* When a server starts, the starting polygons spawn every frame instead of immediately spawning.
* A new and improved UI was originally planned, but this was postponed, before eventually canceled.
** Some features that came with it stayed, however, such as keybinds and the shadow option. The former can be found in the game's Menu, while the latter can be used via [[Console]].
* Capture the Flag has a shorter preparation timer than in the main game (3 minutes instead of 5).
