= Console =

[[File:Screenshot_(110).png|thumb|400px|A picture of what the Console looks like in-game.]]
[[File:Home-key.jpg|thumb|220px|The location of the Home key on a keyboard.<ref name="consoleimage1">Remember to have Num Lock off.</ref>]]

The '''Console''' can be accessed by pressing the Home button<ref name="console-mac"><code>Fn &larr;</code> on a Mac; <code>Ctrl Alt ^</code> on a Chromebook.</ref> and appears at the top of the screen. It works similarly to Chrome Developer Tools, allowing players to enter different commands and variables that can customize the game, mostly for coloring and rendering. Press Home again to close the Console. Reloading the page resets all commands, so they must be entered again. The Console cannot be activated on phones or tablets, as there is no Home key on their keyboards.

Note: The color commands below use the default values. Players can replace the hexadecimal colors with their own. (The hex colors use the format <code>0xRRGGBB</code>, where <code>RR</code> is the red value in hexadecimal, <code>GG</code> is the green value in hexadecimal, and <code>BB</code> is the blue value in hexadecimal. Each value must be two digits, so a leading zero can be added if needed. Opacity values use <code>0</code> for transparent and <code>1</code> for solid, with decimals representing values in between.)

==Trivia==
* The Console was inspired by a feature that can be opened by pressing the Home button in [http://www.muchgames.com/games/diepix-heroes-beta Diepix 2 (Diepix Heroes Beta)], a game made by Zeach.
** Commands: <code>sentrygoingup</code>, <code>m28</code>, <code>givemethekeys</code>, <code>join_class ''Class name''</code>, <code>about</code>, <code>whatsnew</code>.
* Multiple commands can be executed at once by separating them with <code>;</code>. Example: <code>ren_background_color 0;ren_grid_color 0xffffff</code>.
