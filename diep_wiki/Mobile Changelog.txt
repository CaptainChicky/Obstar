= Mobile Changelog =

[[File:Info Version.jpg|thumb|The version information that can be found in the Info section of the settings before version 2.0.0]]
<b>[[Diep.io Mobile]]</b> has received several updates throughout its history, adding new [[Tanks]], [[Game Modes]], etc. However, most of these updates are completely separate from the web version and add features in a much less frequent manner. Some of the updates only apply to one platform or come out in one platform sooner than the other (iOS or Android).
